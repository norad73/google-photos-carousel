Google Photos Fullscreen Gallery

What it does
- Open https://photos.google.com
- Click a photo.
- Chrome enters true fullscreen automatically.
- Use Google Photos' normal Left / Right arrow keys to move through photos.
- Press Esc to exit fullscreen.

Install
1. Unzip this folder.
2. Open chrome://extensions
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select the unzipped google-photos-fullscreen-gallery folder.

No permissions beyond running on photos.google.com are requested.
